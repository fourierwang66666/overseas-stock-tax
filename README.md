## 一、为什么有这个项目？

2025 年起，国内多地税务机关密集向通过富途/长桥/老虎等海外券商交易港美股的境内自然人发出**补税通知**：

- 北京、上海、深圳、厦门、四川、山东、湖北、浙江均已有公开案例，金额从 12 万到 698 万不等
- 触发原因：**CRS 自动信息交换** 已落地，香港税务局向中国国税总局共享了富途/长桥账户数据
- 核心政策：境外股票转让差价属于"财产转让所得"，按 **20% 比例税率** 申报；**亏损不可跨年结转**；**亏损年度仍需补股息税**

但实操中存在三个痛点：
1. 富途/长桥**不出具中国税务口径的成本基础报告**
2. 多年成百上千笔交易、买入卖出穿插、含分红/拆股/转仓 — **手工算几乎不可能正确**
3. 加权平均法 vs FIFO，各地税局口径不统一 — **算法选错可能多缴几十万**

本 skill 是为这个真实场景而生：**把券商原始流水 → 转成税局认可的申报底稿 + 引导依法纳税**。

## 二、整体前提：你需要先准备什么？

### 2.1 下载历年股票交易明细（最关键）

skill 不能凭空算。你必须先从券商下载完整历史交易记录。下面是两家主流券商的下载方法。

#### 富途证券 / Moomoo（香港主体）

**方式 A · 月结单 PDF**（最稳定，所有历史都能下）
1. 打开富途牛牛 APP（或桌面端）
2. **账户 → 账户与服务 → 报表中心 → 月结单**
3. 选择年月（**逐月下载**，至少覆盖你想申报的全部年份）
4. PDF 密码：可能为身份证号后 6 位 / 手机号后 4 位 + 身份证后 4 位 / 自设密码（不同时期/地区不同，第一次下载会询问）

**方式 B · 年度账单 Excel**（推荐，结构清晰）
1. APP 内 **账户 → 资产 → 历史账单** → 选择年度 → 导出
2. Excel 包含 11 个 sheet：**证券-交易流水 / 证券-资金进出（分红）/ 证券-资产进出（转仓）** 是 skill 主要消费的三个

**方式 C · OpenAPI**（适合技术用户，可批量拉历史）
- 文档：https://openapi.futunn.com/futu-api-doc/
- 个人可开通，行情费用：内地 IP 免费港股 LV2 + A 股 LV1
- 端点：`get-history-order-fill-list`

> ⚠️ 富途自 2025-06 起关闭内地新户开通；老用户仍可下载历史月结单与年度账单。

#### 长桥证券（Longbridge / Longport）

**月结单 PDF**
1. 长桥 APP 或 Web Trade
2. **我的 → 清算管理 → 结单管理**
3. **逐月下载**全部历史
4. **PDF 密码 = 手机号末 4 位 + 开户证件号末 4 位**（连续 8 位数字）

**临时结单**（自定义日期范围，单份最多 3 个月）
- 同上路径 → **创建临时结单**

> 📝 长桥**不提供**中国税务口径的成本基础报告；持仓盈亏栏位不能直接用于税务申报。

#### 其他券商（老虎、雪盈、IBKR 等）
本 skill 当前主力支持富途与长桥。其他券商可导出 Excel 后通过 `parse_excel.py` 兜底读取（字段映射可能需手工调整）。

### 2.2 准备人民币汇率历史中间价

财产转让所得需按法定汇率口径换算。`assets/cny_mid_rate.json` 已内置 2018-2024 年末汇率；新年份请从以下渠道手动更新：
- 国家外汇管理局：http://m.safe.gov.cn/safe/rmbhlzjj/
- 中国货币网：https://www.chinamoney.org.cn/

### 2.3 收集境外完税凭证（如有分红）

- 美股分红 → **1042-S 表**（券商或券商网站可下载）
- 港股股息 → 股息凭单 / Composite Statement
- 用于享受境外税收抵免

### 2.4 跨券商持仓转移（如适用）

如果你有股票从 A 券商转到 B 券商（如富途↔长桥），你必须从原券商获取**成本结转单**——只有这样 skill 才能正确接续成本基础。

## 三、整个项目的实现方式与计算方法

### 3.1 核心架构

```
用户上传券商流水 (PDF/Excel)
    ↓
parse_futu.py / parse_longbridge.py  ← 严格用脚本解析（禁视觉识别）
    ↓
统一事件流 (Trade + Dividend + Transfer + CrossBrokerTransfer + CorporateAction)
    ↓
cost_basis.py  ← 4 种成本算法并行计算
    ↓
fx_rate.py     ← 双轨汇率换算（法规 / 实操）
    ↓
compute_tax.py + penalty.py  ← 应纳税额 + 滞纳金
    ↓
reconcile.py   ← 5 节点对账（数据完整性 / 算法不变量 / 期间勾稽 / 金标准回归 / 最终复核）
    ↓
render_report.py
    ↓
4 份 Excel 输出（底稿 / B 表字段 / 算法对比 / 综合报告 + 合规建议）
```

### 3.2 四种成本基础算法

| 算法 | 实现要点 | 法律依据 / 适用场景 |
|---|---|---|
| **滚动加权平均（默认 / 金标准）** | 每次买入更新平均成本；卖出按"卖前平均成本"算收益；剩余持仓平均成本不变 | 国家税务总局公告 2014 年第 67 号（参照适用）+ 项目内"案例校验版"已被地方税局接受 |
| 移动加权平均 | 与滚动加权平均在逐事件粒度等价 | 同上 |
| FIFO 先进先出 | 维护批次队列，卖出从队头逐批扣减 | CRS 国际惯例；某些税局口径 |
| 个别计价 | 用户在买入时打 `lot_tag`，卖出指定批次 | 大宗持仓 / 套保策略；事后无法构造 |

四种算法的税基差异**最高可达 30-50%**，skill 全部并算输出对比表。

### 3.3 公司行为完整支持

| 事件 | 算法处理 |
|---|---|
| **拆股 (Split)** 10:1 | 数量 × 10，单位成本 ÷ 10，总成本不变 |
| **合股 (Reverse Split)** 1:10 | 数量 ÷ 10，单位成本 × 10 |
| **送股 / 红股 (Bonus)** 10 送 3 | 数量增加 30%，总成本不变（成本摊薄） |
| **配股 (Rights)** 1:5 @ 8 | 增加 20% 数量 + 按 8 元入账新批次 |
| **ADR 比例调整** | 同拆股逻辑 |
| **以股代息** | 视同送股处理；现金部分独立记入 Dividend |

### 3.4 转仓事件支持

| 类型 | 处理 |
|---|---|
| **同券商内部转仓**（账户升级 / 账号迁移） | Out 释放成本到 pending，In 消费 pending；成本完整结转，不产生应税事件 |
| **跨券商转入**（富途 → 长桥等） | 用户必须提供 `CrossBrokerTransfer` 原值结转单，否则会按 0 成本入账并告警 |

### 3.5 关键政策口径

依据：财政部 税务总局公告 **2020 年第 3 号**

- **税目**：财产转让所得（卖出差价）+ 利息股息红利所得（分红）
- **税率**：均按 **20% 比例税率**
- **互抵**：依据国税函[2006]1200 号，**同一年度同一国别**内允许盈亏互抵；**跨年度不可结转亏损**；**跨国别不可互抵**
- **汇率**：法规口径用申报年 12-31 中间价；实操口径用买入日上月末锁定原值（双轨输出）
- **申报期**：次年 3 月 1 日 — 6 月 30 日，自然人电子税务局《B 表》
- **滞纳金**：每年独立起算（次年 7-1），按日万分之五（年化 18.25%），不可减免

### 3.6 输出 4 份 Excel

| 文件 | 内容 |
|---|---|
| `01_逐笔交易底稿_{年份}.xlsx` | 完整成交 + 4 算法成本追踪 + 双汇率换算（税局可调阅） |
| `02_B表填报字段_{年份}.xlsx` | 直接对应电子税务局《年度自行纳税申报表（B 表）》+《境外所得抵免明细表》 |
| `03_四算法对比表_{年份}.xlsx` | 4 种算法 × 2 种汇率口径，8 个税基对比 + 选择建议 |
| `04_税务综合报告与合规建议_{年份}.xlsx` | 税务摘要 + 10 条合法节税建议 + 8 项风险提示 + 强制合规声明 |

### 3.7 五节点对账（输出前阻塞门）

任何一个节点失败都拒绝输出：
1. **数据完整性** — 解析输出与原始 PDF 笔数/金额对账
2. **算法不变量** — 4 算法的期末持仓必须一致
3. **期间勾稽** — sum(逐笔) == sum(月度) == sum(季度) == sum(年度)
4. **金标准回归** — 案例校验版 2021-02 月度收益必须 = 15,000.00 元
5. **最终复核** — Excel 字段与 B 表对齐（独立 Agent 复核）

## 四、安装与使用

### 4.1 作为 Claude Code skill 使用（推荐）

```bash
# 1. 克隆到 ~/.claude/skills/
cd ~/.claude/skills
git clone https://github.com/fourierwang66666/overseas-stock-tax.git

# 2. 安装 Python 依赖
pip install pdfplumber openpyxl pypdf

# 3. 在 Claude Code 中触发
# 直接说："帮我算 2024 年富途海外股票个税"
# Skill 会自动加载并按 8 步工作流引导
```

### 4.2 命令行直接使用

```bash
cd scripts/

# 1. 解析富途月结单 PDF → JSON
python3 parse_futu.py 富途月结单_2024-12.pdf --password XXXX --out trades.json

# 2. 跑 5 节点对账
python3 reconcile.py --trades trades.json

# 3. 生成 4 份 Excel
python3 render_report.py --trades trades.json --year 2024 --out-dir ./output
```
