# 08 — 滞纳金与境外抵免计算

## 1. 滞纳金

依据：《税收征管法》第 32 条
> 纳税人未按规定期限缴纳税款的，由税务机关责令限期缴纳，从滞纳税款之日起，**按日加收滞纳税款万分之五**的滞纳金。

### 1.1 关键规则
- **每个所得年度独立起算**
- 起算日 = **该所得年度的次年 7-1**（因为申报期是 3-1 至 6-30，6-30 仍在期内不算迟）
- 终止日 = 实际补缴日
- 每日万分之五 = **年化 18.25%**（高于多数贷款利率）
- 多年累积补税时，**不能合并计算**，必须按年独立累计

### 1.2 公式
```
某年度滞纳金 = 该年度应补税额 × 0.0005 × (实际补缴日 - 起算日 的天数)

例：2022 年度应补税 100 万，2025-12-31 才补缴
天数 = (2025-12-31 - 2023-07-01) = 914 天
滞纳金 = 1,000,000 × 0.0005 × 914 = 457,000 元
```

### 1.3 减免规则
- **滞纳金不可减免**（兰迪律所、安永共识：只有税务机关责任方可不征）
- 罚款（0.5—5 倍）可减免：30 天内主动补税申报通常免罚

## 2. 境外已扣税款抵免

依据：财政部 税务总局公告 2020 年第 3 号 第三、四、五条

### 2.1 抵免限额计算
- 按"**分国不分项**"原则
- 同一国别内：不同所得类型（综合所得 / 经营所得 / 财产转让 / 利息股息红利 / 偶然 / 其他）**分别计算抵免限额**
- 公式：
```
某国某项目抵免限额 = 该国该项目应纳税所得额 × 中国税率
                  = 该国该项目应纳税所得额 × 20%（财产转让 / 利息股息红利所得）
```

### 2.2 实际抵免额
```
实际抵免额 = min(境外已缴税款, 抵免限额)
```
超限部分可在以后 5 个纳税年度内继续抵免。

## 3. 中美 / 中港 / 中新税收协定预扣率

| 协定 | 股息预扣（持股 < 25%） | 利息预扣 | 资本利得 |
|---|---|---|---|
| 中美（W-8BEN 后） | 10% | 10% | 不征收（美方），中方按 20% |
| 中港 | 10% | 7% | 不征收，中方按 20% |
| 中新 | 10% | 7% | 不征收，中方按 20% |

**注意**：
- W-8BEN 必须主动提交才能享受 10% 预扣（默认 30%）
- 港股 H 股股息预扣实务上是 10%（中港协定），红筹股可能不预扣
- 资本利得各国均不征，但中国全额征 20%

## 4. 美股股息抵免示例

```
2024 年度：分红 USD 1,000，美方预扣 USD 100（10%）
12-31 USD/CNY 中间价 = 7.1884

折人民币：
- 收入 = 1,000 × 7.1884 = 7,188.40
- 已预扣 = 100 × 7.1884 = 718.84

中国应纳税额 = 7,188.40 × 20% = 1,437.68
抵免限额 = 7,188.40 × 20% = 1,437.68
实际抵免 = min(718.84, 1,437.68) = 718.84
中国实际补缴 = 1,437.68 - 718.84 = 718.84
```

最终税负 = 美 10% + 中 10% = 综合 20%。

## 5. skill 实施要求

`scripts/penalty.py`:
- 输入：每年度应补税额、用户指定的"实际补缴日"
- 输出：每年度滞纳金 + 总滞纳金 + 占应补税额比例

`scripts/compute_tax.py`（境外抵免部分）:
- 按国别分组计算抵免限额
- 与境外完税凭证对账
- 输出《境外所得抵免明细表》对应字段

## 6. 边界

- 抵免必须凭**境外完税凭证**（美股 1042-S、港股股息凭单）；无凭证 = 不能抵免
- 5 年内未抵完的可结转，但需逐年保留底稿
- 中国境外股息红利已扣的也可抵，但必须分国分项
