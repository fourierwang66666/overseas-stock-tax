# 07 — 税局认可的加权平均算法（金标准）

> 本文档描述本 skill 默认采用的滚动加权平均算法。
> 该算法在多地税务师实务中被广泛使用，部分地方税务局已明确接受；其他三种算法仅作对比。
> 注意：本算法**非全国统一标准**。其他城市可能要求不同方法（特别是 FIFO）。最终申报口径以主管税务机关认定为准。

## 1. 数据结构

逐笔事件表（每行 = 一次持仓变动）：

| 字段 | 类型 | 说明 |
|---|---|---|
| 日期 | date | YYYY-MM-DD |
| 股东名称 | str | 自然人姓名 / 主体名称 |
| 证券代码 | str | 港股 5 位数字、美股股票代码 |
| 证券名称 | str | 中文/英文简称 |
| 变动前持股数量 | int | 事件发生前的总持仓 |
| 变动前持股成本 | decimal | 事件发生前的总持仓成本（人民币） |
| 增加数量 | int | 本次买入数量（无买入则为 0） |
| 减少数量 | int | 本次卖出数量（无卖出则为 0） |
| 变动后持股数量 | int | 事件发生后的总持仓 |
| 变动后持股成本 | decimal | 事件发生后的总持仓成本（人民币） |
| 交易单价 | decimal | 本次成交均价（含费用前） |
| 实际减持收益 | decimal | 卖出时计算（买入时为 0） |
| 年月 | str | YYYY-MM |
| 年份 | int | YYYY |
| 季度 | str | YYYYQn |
| 月度平均成本 | decimal | 当月期末平均成本 |
| 季度平均成本 | decimal | 当季期末平均成本 |

## 2. 算法核心规则

### 2.1 买入事件
```
新持仓数量 = 旧持仓数量 + 买入数量
新持仓总成本 = 旧持仓总成本 + (买入数量 × 买入单价 + 买入费用)
新平均成本 = 新持仓总成本 / 新持仓数量
本笔实际减持收益 = 0
```

### 2.2 卖出事件
```
卖出前的平均成本 = 旧持仓总成本 / 旧持仓数量   # 关键：用卖出"前"的平均成本
本笔实际减持收益 = (卖出单价 - 卖出前平均成本) × 卖出数量 - 卖出费用
新持仓数量 = 旧持仓数量 - 卖出数量
新持仓总成本 = 旧持仓总成本 × (新持仓数量 / 旧持仓数量)   # 按比例摊薄
新平均成本 = 新持仓总成本 / 新持仓数量    # 数学上等于 卖出前平均成本（不变）
```

**注意**：卖出**不改变**剩余持仓的平均成本（这是滚动加权平均与某些税法定义的"移动平均"细微差异点）。

### 2.3 同日多笔交易
按"逐事件"处理（按下单时间排序），不做日内合并。如果券商流水只到日粒度，按"同日先买后卖"顺序排（保守）。

### 2.4 跨年度的剩余持仓
**总持仓与平均成本跨年延续**。年初的"变动前持股数量"和"变动前持股成本" = 上一年最后事件的"变动后"。

### 2.5 整笔卖光的处理
当 `减少数量 == 旧持仓数量`：
- `新持仓数量 = 0`
- `新持仓总成本 = 0`
- `新平均成本 = 0`（避免除 0）

## 3. 月度 / 季度 / 年度汇总

```
月度减持收益 = sum(当月所有 sell 事件的 实际减持收益)
季度减持收益 = sum(当季所有 sell 事件的 实际减持收益) = sum(当季月度减持收益)
年度减持收益 = sum(当年所有 sell 事件的 实际减持收益)
```

**关键：互抵规则**
- 同年度内：盈利月 + 亏损月 自然加总（互抵）
- 跨年度：**不结转**（即使去年大亏，今年盈利仍要交税）

## 4. 实务中常见的口径差异点

实务中不同税务师的处理方式略有差异，常见差异点：

| 维度 | 处理方式 |
|---|---|
| 含投资顾问费 | 部分税务师作为独立科目从年度盈亏中扣减 |
| 转入持仓 | 单独标记 "X月转入"，**变动前数量 / 成本 = 0**，转入数量 / 成本 = 实际转入数据。**这意味着原值要由用户提供** |
| 同一日多事件 | 逐笔记录，不合并 |
| 港股通买卖 | 以人民币计价，无需汇率换算（港股通本身就是人民币结算） |
| 现金分红 | **独立列**，不入加权平均成本计算 |

## 6. 加权平均 vs 标准 FIFO 的实战差异

不同算法在含**多次同股票轮转买卖**场景下结果差异可能巨大：
- 加权平均会"摊平"短期波动
- FIFO 在涨势中放大利润、在跌势中放大亏损

**结论**：**算法选择对税额影响巨大**。skill 必须把四个版本结果都展示出来，让用户决策。

## 7. 限制与告警

- ⚠️ 加权平均法非全国统一标准，**不代表北上广深杭都接受**
- ⚠️ 个税法层面无任何成本计价方法的明文规定
- ⚠️ 自然人按"财产转让所得" 20%，合伙企业按"经营所得" 5-35%，**两者税目不同**
- ⚠️ skill 用本算法计算自然人海外股票时，必须额外向当地主管税务机关确认是否接受加权平均法
