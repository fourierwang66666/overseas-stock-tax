# 01 — 政策依据（Policy Foundation）

> 适用：中国境内自然人居民通过富途/长桥直接交易港股、美股的财产转让所得 + 股息红利所得申报。
> 不适用：沪深港通通道、企业主体、限售股减持、员工股票期权。

## 1. 税目与税率

| 所得类型 | 税目 | 税率 | 政策依据 |
|---|---|---|---|
| 卖出股票差价 | **财产转让所得** | **20%** 比例税率 | 《个税法》第二条第(八)项、第三条第(三)项 + 财政部 税务总局公告 2020 年第 3 号第一条第(七)项 |
| 现金分红 | **利息股息红利所得** | **20%** 比例税率 | 《个税法》第二条第(七)项 + 同上公告第一条第(六)项 |
| 利息收入 | **利息股息红利所得** | **20%** | 同上 |

**关键认定**：境外股票转让所得**没有任何免税规定**，与境内 A 股二级市场转让"暂免征"完全不同。

## 2. 边界澄清（高频误区）

### 2.1 沪深港通暂免 vs 富途/长桥
- **沪深港通**（券商 = 内地券商，通道 = 港交所）：内地个人投资港股转让差价**暂免征个税至 2027-12-31**（财政部 税务总局 证监会公告 2023 年第 23 号）
- **富途/长桥**（券商 = 香港持牌主体）：**直接交易港股**，**不属于沪深港通通道**，**不享受暂免**，仍按 20% 缴税
- 这是 2025 年补税潮被税局抓的主要群体

### 2.2 港股股息预扣 vs 中国补税
- 港股 H 股股息：港交所代扣 10-20% → 中国补足至 20%（凭境外完税凭证抵免）
- 港股红筹股股息：部分免征港预扣 → 中国按 20% 全额征收
- 美股股息：W-8BEN 生效后美方预扣 10%（中美协定）→ 中国补 10% → 综合 20%

### 2.3 不在本 skill 范围
- **企业主体**：要交增值税 6%（财税[2016]36 号金融服务）+ 企业所得税 25%
- **港股通直连**：暂免至 2027-12-31
- **限售股**：财税[2009]167 号（核定方法不同）
- **员工股票期权 / RSU**：财税[2005]35 号、财税[2009]5 号

## 3. 申报路径

### 3.1 时间
**取得所得次年 3 月 1 日—6 月 30 日** 自行申报（**没有月度预缴**机制）。
依据：财政部 税务总局公告 2020 年第 3 号第七条。

### 3.2 申报表
- 《个人所得税年度自行纳税申报表（B 表）（居民个人取得境外所得适用）》
- 《境外所得个人所得税抵免明细表》

### 3.3 入口
**自然人电子税务局 Web 端**：https://etax.chinatax.gov.cn → "我要办税 → 综合所得年度汇算 → 取得境外所得适用"
（个税 APP 当前对境外所得字段支持不全，**复杂申报必须走 Web 端**）

### 3.4 附报材料
- 境外完税凭证（美股 1042-S、港股股息凭单等）
- 券商交易流水 / 月结单 PDF
- 成本与收入说明
- 汇率换算工作底稿
- 实务上税局**有权要求提供逐笔交易明细备查**（北京、上海、深圳已多次要求）

## 4. 滞纳金与罚款

| 项目 | 规则 | 依据 |
|---|---|---|
| **滞纳金** | 每个所得年度独立起算，**起算日 = 次年 7-1**；按日万分之五（年化 18.25%） | 《税收征管法》第 32 条 |
| **罚款** | 偷税认定后 0.5—5 倍税款 | 《税收征管法》第 64 条 |
| **刑事责任** | 偷税数额较大且占应纳税额 10% 以上 → 《刑法》第 201 条；首次免责前提是补税完成 | — |
| **主动补税** | 30 天内主动补税 + 申报，**罚款可减免**；**滞纳金不可免**（因只有税务机关责任方可不征） | 焦点财税、兰迪律所实操共识 |

## 5. CRS 数据通道

- 富途证券（香港）有限公司、长桥证券（香港）有限公司均为**香港持牌券商**
- 香港 → 香港税务局 → 中国国税总局（AEOI / CRS 自动信息交换）
- **2025 年是 CRS 数据在国内税局真正落地稽查的第一年**
- 即使开户主体在新加坡 / 开曼，**这些都是 CRS 参与国**，不存在安全区
- 银行跨境收付款也在外管局监控下

## 7. 城市层面规则

各地税局未对"境外股票"出台特别免税政策。统一按全国口径执行，但**执行严格度不一**（详见 `06-五地税局口径与补税案例.md`）。
