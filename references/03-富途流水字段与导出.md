# 03 — 富途流水字段与导出

## 1. 主体确认

- **富途证券（香港）有限公司** — CRS 申报至香港税务局 → 中国国税总局
- 富途控股注册地：开曼（开曼也是 CRS 参与国，无安全区）
- **2025 年 6 月起**：富途已**关闭内地存量用户开新户**，新开户需海外身份证明

## 2. 月结单 / 日结单导出

| 来源 | 路径 | 格式 | 备注 |
|---|---|---|---|
| 富途牛牛 APP | 账户 → 报表中心 → 月结单 | PDF（密码） | 国内版 |
| 富途桌面端 | 清算管理 → 月结单 | PDF（密码） | 同上 |
| Moomoo (海外版) | Account → Statements | PDF | 字段相近但部分英文 |

**密码规则**：**社区共识不统一**，可能为：
- 身份证号后 6 位
- 手机号后 4 位 + 身份证后 4 位
- 自行设置

→ skill 必须在解析 PDF 前**询问用户实际密码**，不要假设。

## 3. OpenAPI

- **个人可开通**：APP 完成业务账户开通 + 问卷 + 协议
- **行情费用**：内地 IP 个人客户免费 港股 LV2 + A 股 LV1
- **交易费用**：与 APP 一致，无附加
- 文档：https://openapi.futunn.com/futu-api-doc/

关键端点：`/futu-api-doc/trade/get-history-order-fill-list.html` 历史成交记录
返回字段：`fillId, orderId, code, market, qty, price, fillAvgPrice, createTime, fee` 等

## 4. 月结单常见字段（标准化映射）

| 富途字段 | skill schema 字段 | 备注 |

## 5. 已知坑

- **同一只股票在港股与美股双重上市**（如阿里巴巴 9988.HK / BABA）→ 视为**两只股票**独立计算成本
- **复权 / 拆股**事件富途月结单**不显示**，需查公司公告或第三方数据源
- **港股 5 位代码**前导 0 易丢失（00700 → 700）→ 解析时强制按字符串读取
- **PDF 表格跨页**：富途月结单可能跨多页，`parse_futu.py` 需做跨页拼接

## 6. 第三方工具

- 无任何 SaaS 直接生成中国税务报告
- 用户实操：手动 Excel 整理 + Python 脚本（如 `pdfplumber` + `pandas`）
