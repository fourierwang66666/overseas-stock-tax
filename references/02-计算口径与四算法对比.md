# 02 — 计算口径与四算法对比（核心算法文档）

> 这是 skill 最重要的一份 reference。所有税基计算必须严格遵循本文档定义的规则。

## 1. 应纳税所得额公式

```
应纳税所得额 = 转让收入 - 财产原值 - 合理税费
```
依据：《个人所得税法实施条例》第 16 条。

应纳税额 = 应纳税所得额 × 20%（财产转让所得）

## 2. 互抵规则（关键政策口径）

| 范围 | 是否允许互抵 | 依据 |
|---|---|---|
| **同一年度内** 同一国别 同一所得类型（财产转让所得）盈亏互抵 | **允许** | 国税函[2006]1200 号 + 12366 多地答复 + 财新 / 央广网 2025-08 |
| 跨年度结转亏损 | **不允许** | 个税法 + 兰迪律所、安永实务文章共识 |
| 跨国别互抵（如美股亏 vs 港股盈） | **不允许**（实务主流） | 安永 Tax Alert 2025001 |
| 财产转让所得 vs 利息股息红利所得互抵 | **不允许**（不同税目） | 个税法 |

**实操结论**：
- skill 必须按 `(年度, 国别)` 双维度切池子
- 池内逐笔加总盈亏后，**正数 × 20% = 应纳税额**；负数 → 当年应纳税额为 0，且不结转
- 股息部分独立计算，不与转让所得合并

## 3. 财产原值的四种成本法

法规层面**未明确多笔买入的归集方法**（个税法实施条例第 16 条只规定"以购入价 + 合理费用"）。实务有四种主流方法：

### 3.1 滚动加权平均法 ★ 默认（金标准）

**算法**：每次买入后立即更新平均成本。
```
新平均成本 = (旧持仓数量 × 旧平均成本 + 本次买入数量 × 本次买入价 + 本次买入费用) / (旧持仓数量 + 本次买入数量)
卖出收益 = (卖出价 - 当时平均成本) × 卖出数量 - 卖出费用
```

**依据与优势**：
- 国家税务总局公告 2014 年第 67 号第 17 条（非上市股权管理办法）："个人多次取得同一被投资企业股权的，转让部分股权时，**采用加权平均法**确定其股权原值"
- 实务中**多数税务师参考采用**（包括项目内"案例校验版"已被地方税局接受 — 见 `07-税局认可的加权平均算法.md`）
- 避免短期价格波动的扭曲效应

**劣势**：
- 个税法对二级市场股票**未明文要求** — 仍属参照适用
- 某些税局可能要求 FIFO

### 3.2 先进先出法（FIFO）

**算法**：卖出时按"最早买入的批次"逐批扣减成本。
```
卖出收益 = 卖出价 × 卖出数量 - sum(被扣减的各批次买入成本) - 卖出费用
```

**依据与优势**：
- CRS 国际惯例
- 美国 IRS 默认方法
- 计算结果可逐批追溯，**透明度最高**

**劣势**：
- 在涨势中通常**显示更高利润**（因为先扣的是最便宜的早期买入价）
- 极端情况下税基比加权平均高很多

### 3.3 移动加权平均法

**算法**：与滚动加权平均**几乎相同**，但有些券商对"同一日多笔交易"按日合并加权。

**与 3.1 的差异**：仅在批次合并粒度上略有不同。skill 实现时按"逐笔事件"做（与案例校验版一致）。

### 3.4 个别计价法

**算法**：纳税人在买入时为每一批次打标签，卖出时显式指定扣减哪批。
**适用场景**：大宗持仓、套保策略、节税操作。
**要求**：**需在交易时即标注**，事后无法构造。

**skill 实现**：要求用户在上传 Excel 时附 `lot_tag` 字段；如未提供，**退化为 FIFO**（保守起见）并打 warning。

## 4. 四算法税基差异举例

假设：
- 1/15 买入 A 股 100 股 @10 元 = 1,000 元
- 6/20 买入 A 股 200 股 @20 元 = 4,000 元
- 12/10 卖出 150 股 @25 元 = 3,750 元

四种算法的财产原值与应纳税所得额：

| 算法 | 卖出 150 股的对应原值 | 应纳税所得额（不计费用） |
|---|---|---|
| 滚动加权平均 | (1,000 + 4,000) / 300 × 150 = 2,500 | 3,750 - 2,500 = **1,250** |
| FIFO | 100×10 + 50×20 = 2,000 | 3,750 - 2,000 = **1,750** |
| 移动加权平均（同结果） | 2,500 | **1,250** |
| 个别计价（用户指定卖出 6/20 那批） | 150×20 = 3,000 | 3,750 - 3,000 = **750** |

**税额差**：四种方法税基差异最高可达 1,000 元（本例约 30%），实际场景可能差几十万。这是为什么 skill 要四算法并算的核心理由。

## 5. 合理税费扣除

依据：《个税法实施条例》第 16 条 "(转让收入 − 财产原值 − **合理税费**)"。

### 5.1 可扣（社区共识 + 实务通行）

| 费用项 | 港股 | 美股 |
|---|---|---|
| 券商佣金 | ✅ | ✅ |
| 平台费 / 平台使用费 | ✅ | ✅ |
| 印花税（港 0.1%） | ✅ | — |
| 交易所交易征费 | ✅ | — |
| 证监会征费 | ✅ | — |
| 结算费 (CCASS / DTC) | ✅ | ✅ |
| SEC 监管费 | — | ✅ |
| FINRA 交易费 (TAF) | — | ✅ |
| ADR 托管费 | ✅ | ✅（有争议） |

### 5.2 不可扣

- ❌ **融资利息**（杠杆/孖展利息）— 严格说不属于"合理税费"
- ❌ **汇兑损益** — 不属于合理税费
- ❌ 账户管理费、不活跃费

### 5.3 实施细节
- 卖出时的费用：直接从该笔卖出收入中扣
- 买入时的费用：按"购入价 + 合理费用"加入财产原值（不重复扣）

## 6. 汇率换算（双轨）

详见 `05-汇率换算双轨规则.md`。要点：

| 轨道 | 买入金额（财产原值） | 卖出金额（转让收入） | 法规符合度 |
|---|---|---|---|
| **A 法规口径** | 申报年 12-31 中间价 | 申报年 12-31 中间价 | 严格符合实施条例第 32 条 |
| **B 实操口径** | 买入日上月末中间价（锁定原值） | 申报年 12-31 中间价 | 多数税务师推荐，避免汇率波动重复入税基 |

**skill 必须输出两个版本**让用户与税局窗口对比选择。

## 7. 多券商合并

实务共识（社区调研结论）：**同一纳税人的全部境外股票交易合并计算盈亏**。
- 富途账户 + 长桥账户 + 老虎账户 → 按"国别"合并到同一个池子
- 但**跨券商持仓转移**（同一只股票从富途转到长桥）需要用户**手工告知原值**，系统无法自动识别

## 8. 公司行为对成本的调整

| 事件 | 对成本基础影响 |
|---|---|
| 现金分红 | **不调整成本**；分红独立按"利息股息红利所得"申报 |
| 拆股 (split) | 持仓数量按比例放大，**总成本不变**，单股成本按比例缩小 |
| 合股 (reverse split) | 持仓数量按比例缩小，**总成本不变**，单股成本按比例放大 |
| 配股 / 供股 | 按实际付款金额加入总成本 |
| 送股 (bonus shares) | **争议**：保守做法按"零成本送股"（卖出全额计税）；激进做法按"摊薄原成本"。skill 默认保守口径，warning 提示用户向税局确认 |
| ADR 比例调整 | 按调整后比例对应底层股票同等处理 |

**skill 实施**：检测到拆股/合股事件时（数量突变但无对应交易），自动询问用户是否为公司行为；用户确认后按比例调整 `qty` 与 `avg_cost`。
