# 05 — 汇率换算双轨规则

## 1. 法规口径

依据：《个人所得税法实施条例》第 32 条
> 所得为人民币以外货币的，按照办理纳税申报或者扣缴申报的**上一月最后一日人民币汇率中间价**，折合成人民币计算应纳税所得额。
> 年度终了后办理汇算清缴的，对已经按月、按次或者按年预缴税款的人民币以外货币所得，不再重新折算；对应当补缴税款的所得部分，按照**上一纳税年度最后一日**人民币汇率中间价折算。

**境外股票申报场景**：年度自行申报（次年 3-6 月） → 用 **上一纳税年度最后一日（12-31）人民币中间价**

汇率口径：**中国外汇交易中心** 公布的人民币汇率中间价

## 2. 实操中的两套口径冲突

| 场景 | 严格法规 (轨道 A) | 实操主流 (轨道 B) |
|---|---|---|
| 卖出收入 | 申报年 12-31 中间价 | 申报年 12-31 中间价 |
| **买入原值** | 申报年 12-31 中间价（同上） | **买入日所在月最后一日中间价**（锁定原值） |

### 为什么实操偏离法规

按法规口径，**3 年前用 800 港币 / USD 买入 + 今年用 900 港币 / USD 卖出**，本来人民币意义上没赚钱（甚至亏了），但因为**两端都用今年汇率**：
- 买入折人民币 ≈ 卖出折人民币 → 财产转让所得 = 港币差价 × 今年汇率
- 等于把**汇兑收益变相计入应税所得**

这不合理。中瑞财税、中伦律所等推荐"买入日锁定原值"以避免这种重复入税。

### skill 的处理
**双轨同时输出**：
- 轨道 A：严格符合实施条例，被税局接受概率 100%，但通常税额更高（汇率涨）或更低（汇率跌）
- 轨道 B：经济实质合理，主流税务师推荐，但少数税局可能不认

让用户在与主管税务机关沟通时灵活选择。

## 5. 已知坑

- **节假日**：12-31 若为周末或节假日，按当日中国外汇交易中心公布的最近一个工作日中间价（一般是 12-30 或 12-29）
- **港币与美元的关联**：港币是联系汇率制（盯住美元 7.75-7.85），HKD/CNY 中间价波动主要来自 USD/CNY
- **人民币离岸价 (CNH) 不是中间价**：很多用户混淆，必须用在岸 CNY 中间价
